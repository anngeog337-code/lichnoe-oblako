# Архитектура

## Поток данных

1. Пользователь входит через Supabase Auth.
2. Интерфейс GitHub Pages передаёт JWT в `cloud-api`.
3. Функция проверяет пользователя и права через Supabase/PostgreSQL.
4. Для загрузки функция создаёт multipart upload в приватном B2 и возвращает временные URL частей.
5. Браузер загружает части напрямую в B2; функция завершает загрузку и обновляет метаданные.
6. Для скачивания функция проверяет права и выдаёт временный signed URL.

Файлы не проходят через GitHub Pages, Supabase Edge Functions или PostgreSQL. Секреты находятся только в Supabase Function Secrets.
